# Jonas Risbrandt

I'm a developer, software architect and mentor based in Sweden. I've been programming for 35 years, 25 of them professionally, and I'm still just as fascinated by what you can build with code.

I've worked across the software stack, from 68000 and x86 assembly, low-level optimization, algorithms and data structures to software architecture and system design. I once lived and breathed real-time 3D graphics and GPU programming. These days, much of my work focuses on data, machine learning and AI.

This is where I share side projects, experiments and things I build simply because I find them interesting.

## Selected projects

- [Flow Lab](https://github.com/jonasrisbrandt/FlowLab) — An interactive 3D fluid laboratory with GPU simulation and WebGPU rendering. [Try it](https://jonasrisbrandt.github.io/FlowLab/).
- [pt2-web](https://github.com/jonasrisbrandt/pt2-web) — A browser port built around Olav “8bitbubsy” Sorensen's ProTracker 2 clone, with a WebAssembly engine and a TypeScript interface.
- [ShaderLoom](https://github.com/jonasrisbrandt/shader-graph-lab) — A WebGL2 render graph and browser editor for experimenting with shaders. [Try it](https://jonasrisbrandt.github.io/shader-graph-lab/).
- [Full-screen raster bars](https://github.com/jonasrisbrandt/full_screen_raster_bars) — An Amiga 500 demo in 68000 assembly, using the Copper and synchronized interrupts.
- [2D fluid simulation](https://github.com/jonasrisbrandt/fluid-sim-2d) — An interactive fluid simulation in JavaScript and GLSL, running on the GPU through WebGL2.
